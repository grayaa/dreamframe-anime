Privacy Policy

Dreamframe Social Poster · last updated 3 November 2026 (added youtube.force-ssl)

What the app is

Dreamframe Social Poster is a private tool run by the owner of Dreamframe Anime on their own computer. It uploads and schedules the owner's own videos to the owner's own YouTube channel and Facebook Page. It has no other users and no public sign-up.

Google / YouTube data

With the account owner's consent, the app uses the YouTube Data API with these permissions:

  • youtube.upload: to upload videos and set their title, description, tags, privacy and scheduled publication time;
  • youtube.readonly: to read the name and ID of the connected channel, to confirm the right channel is linked.
  • youtube.force-ssl: only to change the visibility or scheduled publication time of the owner's own videos already uploaded with the app (videos.update, status part). Nothing else is edited or deleted.

The OAuth token is stored only in a local file on the owner's computer. No YouTube or Google user data is sent to any server operated by us, shared with third parties, sold, or used for advertising. The app does not read viewers' data, comments or analytics.

Dreamframe Social Poster's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.

Facebook / Instagram data

A Page access token, stored only on the owner's computer, is used to publish the owner's videos to the owner's Facebook Page (and, once linked, Instagram account). No other people's data is collected.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions (Google) or in Facebook's Business integrations settings. Deleting the local token files removes all stored data.
